## Brand & Style

This design system targets technical elites, engineering leaders, and product architects through a synthesis of Linear's obsessive density, Vercel's stark geometric minimalism, and Apple Pro's material luxury. It frames Harshit Meena's engineering footprint—distributed systems, agentic architectures, and low-latency infrastructure—not merely as code, but as high-performance physical precision instrumentation.

### Visual Aesthetic & Philosophy
- **Precision Glassmorphism:** Translucent, multi-layered structural panels that reject murky opacities in favor of high-specular rim lighting, micro-hairlines, and calibrated refractive blurs.
- **Controlled Iridescence:** Ambient radial energy blooms in deep cobalt, hyper-cyan, and electric violet bleed softly behind ultra-structured foreground components without compromising readability.
- **Architectural Bento Topology:** Modular, dynamic grid sections with intentional hierarchy shifts, mimicking hardware chassis interfaces, server cluster telemetry, and cleanroom hardware documentation.
- **Micro-Kinetics:** Subtle state transitions, laser-etched dividers, and living status nodes providing persistent feedback of runtime activity and distributed uptime.

## Colors

The palette leverages an ultra-crisp, bright frosted surface grounded by deep obsidian structures, saturated optical signals, and ethereal ambient glows.

### Foundational Surfaces
- **Canvas Base:** `#F8FAFC` to `#F1F5F9` subtle linear gradient with fixed viewport background meshes.
- **Obsidian Core (Primary Text / High-Contrast Elements):** `#090D16` and `#0F172A` delivering razor-sharp typographic legibility.
- **Subordinate Text:** `#475569` (Slate 600) for structural narrative; `#64748B` (Slate 500) for secondary metadata.

### Translucent Glass Layers
- **Panel Primary:** `rgba(255, 255, 255, 0.72)` with `backdrop-filter: blur(16px) saturate(180%)`.
- **Panel Elevated:** `rgba(255, 255, 255, 0.88)` with `backdrop-filter: blur(24px) saturate(200%)`.
- **Specular Rim Highlight:** `1px solid rgba(255, 255, 255, 0.95)` on top/left edges blending to `rgba(226, 232, 240, 0.6)` on bottom/right edges.

### Optical Accents & Telemetry
- **Aurora Indigo (`#4F46E5`):** Structural highlights, primary interactive anchors, and active tab indicators.
- **Electric Cyan (`#06B6D4` / `#0284C7`):** Agentic workflows, distributed telemetry, and streaming data markers.
- **Telemetry Emerald (`#10B981`):** Live execution states, cluster health pulses, and real-time operational orbs.
- **Deep Cobalt Bloom (`#2563EB`):** Ambient background glow accentuating depth underneath critical dashboard modules.

## Typography

The typographic hierarchy couples high-tension grotesque forms with surgical fixed-width data tags.

- **Headline Rendering:** Geist headlines require negative letter-spacing (`-0.03em` to `-0.04em`) to mirror Swiss modernist signage transformed for high-density silicon dashboards. Headings must utilize dark obsidian (`#090D16`) with zero subpixel fringing.
- **Narrative Body:** Inter delivers uninterrupted horizontal tracking across long-form architecture logs, case studies, and engineering breakdowns. Set at Slate 600 (`#475569`) to balance contrast against pure white card surfaces.
- **Telemetry & Metadata:** JetBrains Mono powers infrastructure metrics, distributed tracing hashes, payload latencies, and micro-labels. Capitalized data labels run with positive letter-spacing (`0.06em`) to command structural separation.

## Layout & Spacing

Layouts conform to an asymmetric 12-column Bento Grid bound to an 8pt architectural rhythm, optimized for deep technical narratives and telemetry data density.

### Bento Architecture
- **Desktop (>= 1200px):** 12-column grid within a max-width of `76rem` (`1216px`), centered with dynamic fluid side padding. Gutter is locked to `1.25rem` (`20px`). Bento modules leverage irregular column-span pairings (e.g., 8+4, 7+5, 4+4+4) to produce tactile variety.
- **Tablet (768px - 1199px):** Reflows to an 8-column layout. Column spans consolidate into symmetrical halves (4+4) or single dominant spans with full-bleed companion metrics.
- **Mobile (< 768px):** Collapses to single-column stacking with edge margins tightened to `1rem`. Dense micro-dashboards remain horizontally scrollable or convert to compact accordion-based telemetry strips.

### Spacing Philosophy
Internal component padding enforces a strict 4px/8px incremental rhythm: tags utilize `space-3xs` x `space-xs`; cards feature deep breathing margins using `space-lg` to `space-xl` internally, preserving the airy Apple Pro material distinction.

## Elevation & Depth

Visual depth is achieved through optical diffraction and specular hairline borders rather than muddy cast shadows.

### Elevation Hierarchy
1. **Base Layer (L0):** The frosted canvas containing deep, organic atmospheric mesh gradients (`rgba(6, 182, 212, 0.08)`, `rgba(99, 102, 241, 0.08)`, `rgba(37, 99, 235, 0.05)`) with an ultra-wide blur radius (`120px` to `180px`).
2. **Surface Layer (L1 - Bento Cards):** Background `rgba(255, 255, 255, 0.75)`, blur `16px`, enclosed by a composite border: `1px solid rgba(255, 255, 255, 0.85)` at the top, transitioning to `rgba(203, 213, 225, 0.4)` at the base. Ambient dual shadow:
   - Primary: `0 1px 2px rgba(15, 23, 42, 0.03)`
   - Specular depth: `0 8px 24px -6px rgba(15, 23, 42, 0.05)`
3. **Elevated Dynamic (L2 - Popovers, Active Nodes, Floating Dock):** Background `rgba(255, 255, 255, 0.92)`, blur `24px`. Border: `1px solid rgba(255, 255, 255, 1.0)`. Dual-layer shadow:
   - Ambient drop: `0 12px 36px -8px rgba(15, 23, 42, 0.08)`
   - Rim reflection: `inset 0 1px 0 0 rgba(255, 255, 255, 0.9)`
4. **Interactive Hover Lift:** On hover, surfaces translate `-1px` on the Y-axis, the specular border shifts to `rgba(99, 102, 241, 0.35)` or `rgba(6, 182, 212, 0.35)`, and a subtle indigo tint blooms from within the box-shadow profile: `0 12px 30px -4px rgba(79, 70, 229, 0.08)`.

## Shapes

The design uses balanced curves (Option 2) calibrated across outer frames and internal children:

- **Large Bento Containers:** `rounded-2xl` (`1.25rem` / `20px`) for major structural viewports.
- **Embedded Modules / Sub-cards:** `rounded-xl` (`0.875rem` / `14px`) to preserve concentric inner-corner balance relative to the outer container.
- **Input Fields, Tooltips & Action Buttons:** `rounded-lg` (`0.5rem` / `8px`) establishing mechanical precision.
- **Status Pills, Badges & Avatars:** Fully rounded pill silhouette (`9999px`) to contrast stark box geometry.

## Components

### Buttons
- **Primary (Obsidian Core):** Background `#090D16`, text `#FFFFFF`, font weight `500`. Hairline top inner border `inset 0 1px 0 rgba(255, 255, 255, 0.2)`. Hover: `#0F172A`, subtle ambient glow `0 4px 14px rgba(9, 13, 22, 0.2)`.
- **Secondary Glass:** Background `rgba(255, 255, 255, 0.8)`, text `#0F172A`, border `1px solid rgba(203, 213, 225, 0.7)`. Hover: `rgba(255, 255, 255, 1.0)`, border `rgba(99, 102, 241, 0.4)`.
- **Ghost Action:** Transparent background, text `#475569`, hover: background `rgba(241, 245, 249, 0.8)`, text `#090D16`.

### Interactive Status Pills & Badges
- **Live Agentic Pulse:** Pill badge (`rounded-full`) with background `rgba(16, 185, 129, 0.08)`, border `1px solid rgba(16, 185, 129, 0.25)`, text `#065F46`. Houses an emerald status orb: `6px` diameter with an expanding ping ring (`animation: ping 2s cubic-bezier(0, 0, 0.2, 1) infinite`).
- **Holographic / Telemetry Pills:** Gradient border simulated via a `1px` padding wrapper with an iridescent sweep (`linear-gradient(135deg, #06B6D4, #6366F1)`), containing a solid semi-opaque slate backing (`rgba(255, 255, 255, 0.95)`).

### Bento Cards
- Enclosed modules with top specular rim highlights. Card headers use `headline-md` with `label-caps` category indicators floating directly above in uppercase JetBrains Mono.
- Content zones support deep architectural visualizations: distributed trace graphs, latency sparklines, and modular terminal outputs.

### Micro-Charts & Interactive Telemetry Meters
- **Latency Meters:** Segmented tick bars (`2px` width, `8px` height, `2px` gap). Unfilled ticks set to `#E2E8F0`; filled ticks shift dynamically from `#06B6D4` to `#4F46E5`.
- **Sparklines:** Vector SVG lines (`stroke-width: 1.5px`) with zero fill or linear gradient fade (`rgba(6, 182, 212, 0.15)` to transparent). Hovering reveals a vertical guide rule and floating glass micro-tooltip with JetBrains Mono numbers.

### Inputs & Search Command Bar
- Inspired by Raycast and Linear command palettes (`⌘K`). Large glass surface (`backdrop-blur-xl`), `1px solid rgba(255, 255, 255, 0.9)`, embedded keyboard shortcut glyphs inside crisp light gray rounded tags (`KBD` tag styled with `box-shadow: 0 1px 1px rgba(0, 0, 0, 0.1)`). Focus state illuminates a sharp cyan-indigo rim glow.
